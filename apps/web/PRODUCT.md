# Product

## Register

product

## Users

A solo freelancer (developer/designer) running their own gig-hunting operation from a desk, usually in daylight work sessions. They are in a judgment loop: skim many text-heavy postings, decide apply / review / skip fast, and track outreach. The tool is used daily, in short focused bursts.

## Product Purpose

GigPilot is the local web UI for the gig-ops pipeline: scan sources for gigs, triage the inbox, evaluate fit with AI, read evaluation reports, and track leads to a won contract. Success = the user always knows the next action and can decide on a gig in seconds.

## Brand Personality

Calm, factual, operator-grade. Like a well-kept ledger, not a startup landing page. Confidence comes from clarity and density done right, never from decoration.

## Anti-references

- The 2024 AI dark-SaaS look: purple/teal gradients, glassmorphism, glow blobs, noise overlays, pulsing status dots.
- Hero-metric dashboards (big number + gradient stripe cards) that describe instead of direct.
- Card walls where every card shouts every attribute at once.

## Design Principles

1. **Verdict is the only color.** Chrome is neutral ink-on-paper; green/amber/red are reserved for apply/review/skip semantics so color always means a decision.
2. **Every screen answers "what do I do next?"** Dashboards direct, not describe.
3. **One reading surface.** Reports and details open where the user already is; don't bounce them between tabs.
4. **Density with hierarchy.** Rows over cards for triage; the score and title carry the row, everything else is secondary.
5. **Motion conveys state only.** Fast (≤250ms), ease-out, no page-load choreography.

## Accessibility & Inclusion

Body text ≥4.5:1 contrast, visible focus rings, full keyboard operability, `prefers-reduced-motion` respected.
